# Darkspire

Low-poly 3D soulslike: камера сверху, из-за плеча или от первого лица. Мрачное фэнтези по сюжетной
библии проекта: континент Эшмарк, Тёмный Шпиль и Ржавь, которая гноит железо и стирает память.
Мир, персонажи и графика оригинальные.

Said, охотник ордена Серых Плащей, не может умереть окончательно. Каждая смерть у Шпиля
отнимает одно воспоминание.

**Версия 0.3: пролог и глава 1 в 3D, лошади, настройки и смена клавиш.**

* **Пролог. Сожжённая деревня Холлоуд.** Контракт на Пастыря Мора, первая встреча с ним,
  которую нельзя выиграть, и Нэйра, вытащившая Said из огня.
* **Глава 1. Пепельное Пограничье.** Нить-клятва с Нэйрой (общие раны), ржавые стражи
  и Сир Дрейвен на Ржавом мосту. Две фазы, во второй его удары оставляют ржавчину.

## Что внутри

| Папка | Что там |
| --- | --- |
| `game/` | Проект Godot 4.5 (GDScript). Открывается в редакторе Godot как обычный проект. |
| `game/scripts/screens/level3d.gd` | Уровень: мир, триггеры диалогов, Угли Памяти, лошадь, босс, смерть. |
| `game/scripts/3d/` | 3D-модели и анимации (`rig.gd`), лошадь, герой, враги, боссы, камера, карты (`maps.gd`). |
| `game/scripts/settings.gd` | Настройки экрана, звука и переназначение клавиш (`user://settings.cfg`). |
| `game/scripts/data.gd` | Все тексты сюжета, воспоминания, параметры врагов. |
| `game/assets/` | Портреты, шрифты и иконка. Сгенерированы скриптами из `tools/`. |
| `tools/` | Python-генераторы портретов и старой 2D-графики. |

3D-персонажи, лошадь и мир строятся кодом из простых фигур (`game/scripts/3d/looks.gd` задаёт цвета и снаряжение каждого).
Портреты и 2D-графику можно пересобрать скриптами:

```bash
pip install pillow
python3 tools/gen_chars.py    # Said, Нэйра, пеплоед, ржавый страж, Пастырь Мор, Сир Дрейвен
python3 tools/gen_side.py     # тайлы, параллакс-фоны, декор, портреты
```

Звуки и музыка синтезируются при запуске (`game/scripts/sfx.gd`), отдельных аудиофайлов нет.

## Управление

Все клавиши меняются в меню: Настройки → Управление.

| Действие | Клавиатура и мышь | Геймпад |
| --- | --- | --- |
| Идти | WASD или стрелки | левый стик |
| Камера | мышь | правый стик |
| Бег | Shift | L3 |
| Прыжок | Пробел | A |
| Удар (дважды: серия) | ЛКМ или J | X |
| Перекат (неуязвимость) | Ctrl или ПКМ | B |
| Целебная настойка | R или F | Y |
| Взаимодействие, сесть на лошадь | E | RB |
| Захват цели | Q или колесо (нажать) | R3 |
| Вид: сверху / сзади / от первого лица | V или колесо мыши | LB |
| Память | Tab | Back |
| Пауза | Esc | Start |
| Полный экран | F11 или Alt+Enter | |

Клавиши привязаны к физическим кнопкам, поэтому работают и в русской раскладке.

## Сборка

Нужен [Godot 4.5](https://godotengine.org/download) и шаблоны экспорта
(в редакторе: Editor → Manage Export Templates).

```bash
cd game
godot --headless --import
godot --headless --export-release "Windows" ../build/windows/Darkspire.exe
godot --headless --export-release "Linux"   ../build/linux/Darkspire.x86_64
```

Ресурсы вшиваются в исполняемый файл, поэтому игра это один файл плюс README.

Автосборка: при пуше тега `v*` (например `git tag v0.3.0 && git push --tags`)
GitHub Actions соберёт zip для Windows и Linux и приложит их к релизу
(`.github/workflows/build.yml`).

## Раздача со своего сервера

1. Положите `Darkspire-<версия>-windows.zip` и `-linux.zip` в папку, которую отдаёт веб-сервер
   (например `/var/www/darkspire/`).
2. Торрент с вашим сервером в роли вечного сида через веб-сид (BEP 19):

   ```bash
   sudo apt install mktorrent
   mktorrent -a udp://tracker.opentrackr.org:1337/announce \
             -w https://ВАШ-ДОМЕН/darkspire/Darkspire-0.3.0-windows.zip \
             -o Darkspire-0.3.0-windows.torrent Darkspire-0.3.0-windows.zip
   ```

   Клиенты будут качать с вашего сервера по HTTP, даже если других раздающих нет.
3. Рядом выложите `SHA256SUMS.txt`, чтобы игроки могли проверить архив.

## Отладка

* `godot --headless --fixed-fps 60 -- --autotest` прогоняет пролог и главу 1 ботом
  и печатает смерти и итог.
* `godot -- --shot level out.png border 175 4.5 boss` делает скриншот уровня
  (уровень, колонка, задержка, режим).
